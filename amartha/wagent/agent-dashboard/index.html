Notes

1. Sales Summary

A record of the sales that land in the agent's AmarthaLink Poket. Agents can see revenue, profit, and the cashback earned that day, with the option to look back over the last 7 or 30 days.

For a fuller breakdown, agents can open Laporan Keuangan Selengkapnya. That detail page is still in progress for now.

QRIS income is kept separate from the profit figure. If an agent does not have a merchant Poket yet, or is not registered as a QRIS acquirer, this block simply does not appear.

2. Agent Tier & Missions

- Future Development -

To keep agents motivated, this section shows their current tier along with the points they have now and the points still needed to level up. Later on, tier can also drive promo segmentation by level.

Agents earn points by completing the missions they are given, which opens the door to more gamification down the line. Each tier unlocks a different benefit — cashback or physical rewards, for example.

3. Agent Promos

Same as the current agent promo page: this section only carries promo banners meant specifically for agents.

4. Extra Earnings

Another motivation section, but for opportunities outside the assigned missions. It gathers the other ways an agent can add to their income.

5. FAQ

Today agents can only reach out to ARCO or CS when they have a question about their activity. This section surfaces the questions agents raise most often, sourced from NPS and CX feedback.

6. Usahamu

An entry point for the things agents need to keep up to date — business information and location, selling prices per product, and access to the agent community.
